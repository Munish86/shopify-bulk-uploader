Shopify Bulk Uploader

Add your product sheet and images, map the columns, check the matches, then upload to Shopify.

Not connected

1Connect to Shopify

Use your xxxx.myshopify.com address (your website domain also works; the app finds the right address). Required permissions: read_products write_products write_files.

Using a Dev Dashboard app with a Client ID and Secret instead?

2Product sheet

The first row must hold the column names. For products with variants, add one row per variant and repeat the same product key. Download the product template (Excel), which has a column for every field, a filled-in example and a guide.

Drag an Excel (.xlsx) or .csv file here, or

Share the sheet as "Anyone with the link can view", or upload a Google key in step 4 and share the sheet with that email.

Preview the first 5 rows

3Map your columns

Only map what you want to change. Everything is optional: a sheet with just a title and a meta title works. Empty cells never erase data in Shopify.

Then fix anything that looks wrong.

Find each product in Shopify using

Rules are tried from top to bottom; the first one that finds the product is used. A column used to find products by title is not written back as the new title. To rename products, find them by SKU or handle instead.

What to update

Variant options

Columns that define variants (Colour, Size...). The column name must match the option name used in Shopify.

Metafields

Use the namespace.key and type shown in Shopify Admin under Settings, then Custom data, then Products.

4Images

Image file names must match the "Image name" column. Oslo Sofa.jpg, oslo-sofa_1.jpg and Oslo Sofa (2).png all belong to "Oslo Sofa", in that order.

Images are not changed. Choose "From computer" or "Google Drive folder" only when you want to upload images.

Drag your images folder here

Sub-folders are included. Reading Drive needs the Google key below.

Google access (for a Drive folder or a private Google Sheet)

In Google Cloud Console, create a service account, enable the Drive API and Sheets API, and download a JSON key. Upload it here, then share the Drive folder and the sheet with the service account email as "Viewer".

5Update rules

6Run

    Steps 1 and 2 never save anything to Shopify. Run step 3 only when the preview looks right.
